# ✳️ NovaFlow — Interactive Landing Page

An interactive landing page for NovaFlow, a fictional AI-powered assistant platform designed to simplify everyday business workflows. A creative exploration of visual identity, motion, and web design, combining bold typography, fluid gradients, and playful interactions to bring the experience to life.

## ✨ Technologies & Tools

- `Figma` — Visual identity, UI design & prototyping
- `Midjourney` — AI-generated visual assets
- `Claude` — Frontend development
- `HTML5` / `CSS3` / `JavaScript`
- `GSAP` / `ScrollTrigger` — Animations
- `Lenis` — Smooth scrolling

## 🚀 Features

- Animated preloader with percentage counter and logo reveal
- Dynamic typography and smooth transitions
- Scroll-triggered animations and parallax effects
- Interactive hover states and magnetic buttons
- Custom illustrations and animated visual elements
- Fluid purple-blue gradients and bold typography
- Responsive layouts and mobile navigation
- Reduced-motion accessibility support

## 📍 The Process

I wanted to explore how an AI-powered brand could feel innovative and trustworthy without falling into the usual corporate tech aesthetic. Something minimal and functional, but still playful and full of personality.

I started by researching visual references from brands like OpenAI and Microsoft, focusing on typography, whitespace, and clean layouts. From there, I developed NovaFlow's visual identity using soft purple-blue gradients, Poppins typography, and an abstract circular logo inspired by movement and communication.

For the visuals, I combined my own illustrations with AI-generated assets from Midjourney, adapting everything to create a consistent look and feel. I then brought the whole landing page together in Figma, building a clear narrative around the product and its benefits.

Once the design was ready, I worked with Claude to turn it into a functional website. Claude handled all the frontend coding, while I focused on the creative direction, visual decisions, and overall experience. Together, we explored scroll-based animations, interactive elements, and subtle motion effects that made the page feel more dynamic.

It was a fun experiment in combining traditional design tools with AI-assisted development, taking an idea from early visual exploration to a fully interactive landing page!

## 🚦 Running the Project

1. Clone the repository.
2. Open the project folder.
3. Run `npx serve .` or use Live Server in VS Code.
4. Open the local URL in your browser.

**Note:** An internet connection is required to load external libraries and fonts.
